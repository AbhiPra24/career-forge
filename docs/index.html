Installation & CLI Usage

Get Started in Seconds

Install CareerForge in editable mode with modern package configuration:

# Clone and install
git clone https://github.com/AbhiPra24/career-forge.git
cd career-forge
pip install -e ".[dev]"
1. Audit ATS Health: cforge resume audit -r resume.pdf
2. Build Role LaTeX/PDF: cforge resume build -r resume.pdf --role swe -c
3. Match & Generate Report: cforge match -r resume.pdf -q "Backend" --report
4. Verify Recruiter Email: cforge verify-email recruiter@company.com

MCP Configuration

Add CareerForge to your Claude Desktop, Cursor, or AI assistant configuration: 

{
  "mcpServers": {
    "career-forge": {
      "command": "cforge",
      "args": ["mcp-serve"]
    }
  }
}
